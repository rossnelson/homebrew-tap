# homebrew-tap

Homebrew tap for Simian tools.

| Name | Kind | Install |
|---|---|---|
| grove | formula | `brew install rossnelson/tap/grove` |
| Spec Studio | cask | `brew install --cask rossnelson/tap/spec-studio` |

The release pipeline of each tool updates its file here.

Spec Studio has no release yet: the cask holds a placeholder version until the first release, and `brew install` fails until then. The [Spec Studio page](https://rossnelson.github.io/spec-studio-site/) shows the install command when the first release is out.
