# homebrew-tap

Homebrew tap for Spec Studio.

| Name | Kind | Install |
|---|---|---|
| Spec Studio | cask | `brew install --cask spec-studio-app/tap/spec-studio` |
| [plugin-temporal](https://github.com/spec-studio-app/plugin-temporal) | formula | `brew install spec-studio-app/tap/plugin-temporal` |

The release pipeline of Spec Studio updates the cask here. The release pipeline of plugin-temporal writes `Formula/plugin-temporal.rb` at each release.
