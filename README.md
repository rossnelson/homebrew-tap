# homebrew-tap

Homebrew tap for Spec Studio and demo-video.

| Name | Kind | Install |
|---|---|---|
| Spec Studio | cask | `brew install --cask spec-studio-app/tap/spec-studio` |
| demo-video | formula | `brew install spec-studio-app/tap/demo-video` |

The release pipeline of Spec Studio updates the cask here. `scripts/release.sh` in [demo-video-tool](https://github.com/rossnelson/demo-video-tool) updates the formula.
