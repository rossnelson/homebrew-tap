# homebrew-tap

Homebrew tap for Spec Studio.

| Name | Kind | Install |
|---|---|---|
| Spec Studio | cask | `brew install --cask spec-studio-app/tap/spec-studio` |

The release pipeline of Spec Studio updates the cask here.

Spec Studio has no release yet: the cask holds a placeholder version until the first release, and `brew install` fails until then. The [Spec Studio page](https://spec-studio-app.github.io/spec-studio-site/) shows the install command when the first release is out.
